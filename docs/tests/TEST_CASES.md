## 3. Mandatory Execution & Governance Notes

1. **Baseline Execution Scope**: Phase 2 automated baseline executes **CURRENT** test cases only against current code without changes. Every failure will be cataloged in `docs/tests/KNOWN_BUGS.md`.
2. **CI Safety Gate**: All passing CURRENT P1 test cases become blocking CI safety gates. Any regression fails the build and blocks deployment.
3. **Phase 6 Target Switch**: TARGET test cases remain in the catalog and will be activated module-by-module in Phase 6 as data migrations and new authorization matrices are deployed.
4. **Zero Invented Rules**: All ambiguous business rules and unverified constraints have been moved to `docs/tests/QUESTIONS.md` pending explicit user decision.
