## 3. Mandatory Execution & Governance Notes

1. **Baseline Execution Rule**: These test cases are executed in Phase 2 on the current code without modifications to establish the authoritative `BASELINE_REPORT.md`.
2. **UAT Database Isolation**: Automated tests and seed scripts run strictly against the UAT/test database; live production records must never be modified.
3. **Safety Gate Integration**: All P1 test cases are integrated into GitHub Actions CI/CD. Any regression on a previously passing P1 test blocks release deployment.
4. **Zero Client Impersonation**: Tests assert that server actions resolve identity strictly via `supabase.auth.getUser()`, rejecting spoofed caller inputs.
